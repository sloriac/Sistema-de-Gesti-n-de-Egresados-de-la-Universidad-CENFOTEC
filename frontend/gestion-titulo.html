Gestión de títulos

Complete todos los campos obligatorios para registrar un título académico.

Título registrado correctamente.

*
Ingrese el código único del título, por ejemplo: TIC-025 Ingrese un código válido (3letras y 3 números).
*
Ingrese el nombre completo del título tal como se otorga, por ejemplo: Bachillerato en tecnologías de la información y comunicación Ingrese un nombre válido (mínimo 10 caracteres).
*
Ingrese el ID del egresado al que pertenece este título. Ingrese un ID de egresado válido.
*
Ingrese el ID de la escuela a la que pertenece este título. Ingrese un ID de escuela válido.
*
Ingrese el ID de la carrera a la que pertenece este título. Ingrese un ID de carrera válido.
*
Seleccione el nivel o grado académico que otorga este título, por ejemplo: Técnico, Bachillerato, Maestría. Ingrese un grado válido (mínimo 8 caracteres).
*
Ingrese la cantidad de créditos requeridos para optar por este título, por ejemplo: 160 Ingrese una cantidad de créditos válida (mínimo 2 caracteres).
*
Ingrese la fecha desde la cual el título se encuentra vigente, en formato día/mes/año. Ingrese una fecha válida.
*
Indique si el título se encuentra vigente o descontinuado. Ingrese un estado válido (mínimo 7 caracteres).
